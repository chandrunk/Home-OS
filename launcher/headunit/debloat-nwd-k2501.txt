# Google Play Services: Play Store installs GMS as split APKs, and on this Android 10 that makes GMS's bindApplication
# parcel overflow the 512 KB async binder buffer (529 KB for 26.33.32), so GMS never attaches and every retry leaves a
# zygote child stuck <pre-initialized> until the uid's process limit is hit (565 stuck processes, load ~5, half the RAM).
# The factory build (21.09) is too old for YT Music (needs 23.42+) and Maps. Fix used 2026-10-26: the same release as
# ONE APK, Google-signed (cert SHA-256 F0:FD:6C:5B:...:60:DB:83, same as /system/priv-app/PrebuiltGmsCore):
#   APKMirror "Google Play services 26.33.32 (100300-974685114)", armeabi-v7a, Android 9+, nodpi -> adb install -r
# then `am stopservice` on old service records whose class no longer exists (DeviceConnectionWatcherService,
# ExposureMatchingService). Play Store stays disabled so it can't swap GMS back to splits; enable it for a moment
# to install or update an app, then disable it and check `ps -A | grep -c pre-init` stays 0.
com.android.vending              # Play Store
